# 多图成果交付验收 · 2026-09-06

本轮落地优化计划 P0/P1 的多图成果流程：真实文件发布、Feed 引用、传输校验、iPhone 大图分页、原图浏览。基线为 `909df05`。

## 实现

- `material.publish` 回执增加状态、MIME、字节数和 SHA-256，Agent 能确认文件已就绪。
- Rust 拒绝相册中重复的文件 ID，继续校验每个引用确实存在、属于图片且已就绪。
- Agent 交付规范要求逐个发布真实文件，按顺序组成相册，第一张为封面。生成失败必须明确说明；不能用一张图片的不同 CSS 裁剪冒充多份输出。
- 根据后续反馈移除缩略图，改为横向分页与右上角序号。主图铺满可用区域作为封面预览，点开原图查看完整画面；文件名和内容版本移至原图查看器。
- 图片卡压缩页眉、去掉上下弹性留白，让图片区使用主要空间；没有任务关系或验收证据时，不显示空泛的“新任务上下文”页脚。
- Feed 卡片手势依据图片区域边界避让图库；图片区翻页，文字区域保留任务 / 移出操作。图库提供“上一张 / 下一张”可访问操作。
- 原图使用原生 Quick Look：从当前图片打开，支持缩放、文件列表、分享与“完成”退出。打开时固定已加载文件列表，后续下载不会移动正在查看的图片；关闭后重新打开可纳入新下载的文件。
- 先加载所选图片，单个文件失败可重试，其余图片继续可用。加载状态按来源设备、文件 ID、内容哈希隔离，过期异步结果不能覆盖新来源或新版本。
- 卡片显示“成果 / 进展 / 决策”等用户可读标签，移除设计系统字段；图片区采用实色深背景保证文字可读。

## 自动验收

- `pnpm check` 通过，覆盖 TypeScript 测试、类型检查、构建、Rust 格式 / lint / 测试以及写入流程 smoke test。
- 最终 iOS 模拟器测试：76 通过，0 失败。新增覆盖缺失文件占位、相册顺序、来源隔离、版本切换、迟到请求和局部下载失败。
- `scripts/verify-artifact-delivery.mjs` 已接入 `pnpm runtime:smoke:write`：通过真实 Rust 本地 Agent 工具 socket 发布三份不同 PNG，提交一条相册 Feed，经加密 WebSocket 读取结果，再经鉴权文件接口下载。三个下载文件均与发布回执 / 快照中的 SHA-256 一致；未发布 ID、重复 ID 被拒绝，Feed 重放不会重复创建。

复现并导出可供模拟器渲染的回执：

```sh
ZIMLO_ARTIFACT_REVIEW_DIR=/tmp/zimlo-gallery-review pnpm runtime:smoke:write
```

Debug 构建使用启动参数 `--artifact-review-directory=/tmp/zimlo-gallery-review` 打开隔离验收界面。界面使用实际 `FeedPage`、`PostCard` 和图库组件读取 smoke test 导出的 Feed / Material 字段及下载文件；不会启动 Bridge 或写入正常快照缓存。Release 不包含验收入口。

## 界面验收

在 iPhone 17 Pro / iOS 26.5 模拟器中完成：

1. 三份文件显示大图和正确序号；主卡不再显示缩略图、文件名或版本哈希。
2. 通过“下一张”可访问操作确认第二张图片与 `2 / 3` 同步更新；原图查看器显示真实文件名和内容版本。
3. 点“完成”返回，卡片仍选中第二张。
4. 第一张山景原图双击后放大到山峰细节。
5. 原图文件列表列出三份独立 PNG。

最后一轮复验：iOS 76 项通过，架构检查及 `git diff --check` 通过，真实文件写入 smoke test 通过。CUA 鼠标拖拽在模拟器中曾被识别为点按，因此不将该自动拖拽作为真机横滑手势的验收证据；原生分页切换和可访问翻页均已观察。

## 验收范围与后续

### Mac 同步实现

- Mac Feed 已由“最多三张图片并排”改为单张大图，完整保留图片比例，不显示缩略图或文件哈希。
- 上下张按钮、左右方向键和拖动可切图；计数同步，首尾按钮禁用。点击切图后焦点留在图库，方向键继续操作当前相册。
- 原图在 App 内通过 Quick Look 显示，弹窗展示真实文件名和版本，点击“完成”返回后保留原来的选中图片。
- 图片卡不再套整卡任务链接，避免点图时跳走；查看任务有独立入口。图片卡禁用整卡拖动归档，保留右键菜单和可访问归档操作。
- 下载走本机服务身份校验，内容哈希校验后进入按设备 / 文件 ID / 版本隔离的缓存。切换版本或设备时不显示旧加载结果。
- 使用同一份真实交付回执在独立 Debug 应用中验收，不启动 Bridge，不替换日常安装的 App。预览应用：`/tmp/zimlo-mac-gallery-review-20260906/Zimlo Gallery Review.app`。Debug 的 Info.plist 中 `ZimloArtifactReviewDirectory` 指向回执目录；Release 不包含该入口。
- 已在 Mac 窗口中验证：点击下一张、方向键切到第三张、原图弹窗显示所选文件、关闭返回。最终 `swift test --package-path apps/macos` 为 **111 通过，0 失败**；新增测试覆盖跨设备缓存拒绝、错误内容哈希拒绝及新版本独立缓存。架构检查和 `git diff --check` 通过。

三份输入复用了仓库现有的主视觉、手机页面预览、桌面页面预览；它们是三个真实独立文件，不代表本轮让模型生成了三份新海报。传输测试运行在隔离的 Bridge 和设备凭据下；模拟器读取其导出的回执，尚未覆盖实体 iPhone 跨公网现场下载。

本轮没有覆盖全部后续计划。视频 / 文档卡继续使用原有实现；针对具体图片与版本的反馈、版本对比、完整离线下载策略、更多屏幕及大字号验收、官网用真实 App 录屏替换示意内容，仍需后续完成。没有发布新版本或替换日常安装的 macOS App。
