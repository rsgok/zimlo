## 可重复性能证据

运行 `pnpm performance:check`，输出 `dist/product-scale.json`。基线报告保存在 `docs/benchmarks/product-scale-2026-09-06.json`。

条件：Apple silicon Mac、release Rust、单 host、loopback、关闭 Cloud、热数据库；1,000 sessions、10,000 posts、100,000 events，其中 20,000 条用户指令；每项采样 30 次。

| 测量 | p50 | p95 | p99 |
|---|---:|---:|---:|
| 首输入旧查询及转换 | 13.306ms | 15.787ms | 15.884ms |
| 首输入索引查询及转换 | 2.245ms | 3.450ms | 3.865ms |
| 完整 HTTP Snapshot | 13.339ms | 15.828ms | 17.987ms |
| 未变化条件请求 | 0.298ms | 0.477ms | 0.743ms |

完整快照正文 816,084 bytes；条件请求正文 0 bytes。脚本同时验证两种首输入查询结果一致，以及数据库写入会使 ETag 失效。相对回归预算为索引查询 p95 < 旧查询的 65%，条件请求 p95 < 全量的 25%。这些数字不代表手机首屏、Cloud/LAN 弱网、1/3/5 host 或八小时续航测试。

## 试用和成本记录口径

不新增远程埋点 SDK。试用者自愿提供本机汇总，可先检查导出预览；不索取任务标题、代码或文件。主指标只统计成功得到设备回执的任务创建、跟进或审批；同步次数不算有效操作。现有统计按操作计数，不代表跨端去重后的独立任务数或人数。

每位试用者用匿名编号记录：连接各步骤开始/结束、操作是否有回执、是否需要作者帮助、最常见失败原因、有用/无用提醒数。按周汇总有效操作，分别记录新用户与回访者；样本不足时展示人数和原始分子/分母，不输出虚假的留存率结论。

成本从服务提供方账单和自有用量记录计算：活跃 host 数、连接小时、加密转发消息与字节、媒体暂存 GB·小时、读取/写入次数及推送量。单位成本 = 同期可归属成本 / 活跃 host 数；注明币种、周期、免费额度与共享基础费用。没有这些输入前不预设定价或利润率。

Node 参考后端保留迁移对拍，不复制新增历史/增量特性；退出条件是旧客户端兼容向量、真实升级和数据恢复验收均有证据，而不是仅删除重复代码。
